إعداد ربط الذكاء الاصطناعي

شغّل الخادم وأضف مفتاح API في ملف .env. لا تضع المفتاح داخل ملفات الواجهة.

  1. ثبّت Node.js على كمبيوتر أو استضافة تدعمه.
  2. انسخ .env.example إلى .env.
  3. أضف مفتاح المزوّد ثم نفّذ npm install و npm start.
