# AI PRO — موقع عربي تجريبي

## المميزات
- واجهة عربية RTL متجاوبة للموبايل.
- دردشة ذكية ومساعد برمجة عبر خادم API.
- مسار API لتوليد الصور.
- أداة تجهيز وصف فيديو ومعاينة متحركة (لا تنشئ ملف فيديو فعلياً).
- مساحة إعلانية شكلية فقط، وليست إعلانات فعلية.

## التشغيل
تحتاج كمبيوتر أو استضافة تدعم Node.js:
1. ثبّت Node.js LTS.
2. افتح الطرفية داخل المجلد ونفّذ `npm install`.
3. انسخ `.env.example` إلى ملف اسمه `.env`.
4. أضف مفتاح API الخاص بك إلى `OPENAI_API_KEY`.
5. شغّل `npm start` وافتح `http://localhost:3000`.

لا تضع مفتاح API في `index.html` أو `app.js` ولا ترفعه إلى مستودع عام. احفظه في متغيرات بيئة الخادم فقط.

## الخدمات التي تحتاج إعداداً
- الدردشة ومساعد البرمجة: مفتاح API وفوترة فعّالة عند مزوّد النموذج.
- الصور: مفتاح API وصلاحية استخدام نموذج الصور.
- الفيديو الحقيقي: اختر مزوّد فيديو يوفر API وأضف مسار خادم منفصلاً.
- الإعلانات: يلزم حساب ناشر مقبول ومراجعة سياسات الإعلانات والدفع والتوفر في بلدك.

## بداية منخفضة التكلفة
ابدأ بنشر واجهة ثابتة مجاناً، واختبرها بنفسك. عند تفعيل الذكاء الاصطناعي، ضع حدوداً للاستخدام وسجّل التكلفة. تحقق من الأسعار الحالية قبل إتاحة الخدمة للناس. راجع خطة Cloudflare Pages/Workers أو أي استضافة تختارها، لأن حدود الخطط المجانية تتغير.

## قبل الإطلاق
- أضف تحديد معدل الطلبات وحماية من الإساءة.
- أضف سياسة خصوصية وشروط استخدام ووسيلة تواصل.
- أضف تسجيل دخول وقاعدة بيانات فقط إذا احتجت حسابات وسجل محادثات.
- اختبر الموقع على الموبايل.
- لا تنقر على إعلاناتك بنفسك ولا تضع إعلانات قبل قبول حساب الناشر.
